# don't get upsold

You came in for one thing. Leave with one thing.

A tiny, half-serious, single-page site in the spirit of [nohello.net](https://nohello.net): send it to the friend who always walks out with the extended warranty.

Live at **[dontgetupsold.com](https://dontgetupsold.com)**.

## Stack

Plain HTML + CSS + ~20 lines of JS (the typewriter title). No build step.

## Run locally

```bash
python -m http.server 5180
```

## Deploy

Render static site (free), config in `render.yaml`. Auto-deploys on push to `main`.
